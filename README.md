# Compendlore Devtools

## English

Public developer tools for Compendlore. This repository contains the addon compiler and the local
development manager. It must not contain official signing keys, deployment credentials, or release
automation reserved for maintainers.

### Commands

- `npm run pretty`: format the repository;
- `npm run lint`: check code and repository documentation;
- `npm run typecheck`: run strict TypeScript checks;
- `npm run test`: build and execute tests;
- `npm run ci`: run the complete integration checks.

## Français

Outils publics destinés aux développeurs Compendlore. Ce dépôt contient le compilateur d’addons et
le gestionnaire de développement local. Il ne doit contenir aucune clé de signature officielle,
aucun identifiant de déploiement et aucune automatisation de release réservée aux mainteneurs.

### Commandes

- `npm run pretty` : formate le dépôt ;
- `npm run lint` : vérifie le code et la documentation ;
- `npm run typecheck` : vérifie TypeScript en mode strict ;
- `npm run test` : construit et exécute les tests ;
- `npm run ci` : exécute tous les contrôles d’intégration.
